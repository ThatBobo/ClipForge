# 🎬 ClipForge v0.9  
### The pre-release that started it all.

ClipForge v0.9 is the final development build before the official v1.0 launch.  
This version includes the full animation engine, Supabase uploads, EmailJS delivery,  
and the brand-new Besties development team structure.

---

## 🚀 What’s Inside v0.9

### 🎥 Canvas-Based Animation Engine  
- Draws simple objects (cat, dog, ball, car, rocket, sun, house, tree)  
- Animates them using behaviors like jump, run, bounce, drive, launch, slide  
- Renders a 6-second WebM video at 30 FPS

### 📤 Supabase Upload System  
- Uploads the final video to the `videos` bucket  
- Returns a public URL instantly

### 📧 EmailJS Integration  
- Sends a “Your video is ready” email  
- Sends an error email if something breaks

### 🧩 Fully Client‑Side  
- No backend  
- No frameworks  
- Works directly in Spck Editor
